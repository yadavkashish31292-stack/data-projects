# Data Processing & Database Portfolio

This repository contains practical Python and SQL projects demonstrating modular data parsing, JSON serialization, and relational database queries.

## 1. JSON Parser & Data Clean-up (`json_parser.py`)
- **Language:** Python 3 (OOP structure)
- **Key Features:** Loads raw JSON files, validates missing keys, extracts structured attributes, and saves cleaned outputs.
- **Use Case:** Automating data pipelines and API response parsing.

## 2. Sales Data Aggregation (`sales_query.sql`)
- **Database Engine:** SQL / PostgreSQL
- **Key Features:** Uses `GROUP BY`, multi-table `JOIN`s, and conditional filtering to aggregate revenue data.
- **Use Case:** Business performance tracking and data reporting.
